# Landscape details from the historic OS map

Reviewed 23 September 2026 using the [NLS overlay supplied by Tom](https://maps.nls.uk/geo/explore/#zoom=17.3&lat=52.47692&lon=-2.09059&layers=257&b=ESRIWorld&o=100), and the saved wider reference in `artifacts/village/outside-road/nls-route-reference.jpg`.

The viewer identifies this as OS Six Inch, 1830s–1880s (county layers), layer 257.
That is a series range. NLS Map Finder at the supplied point lists the earliest
six-inch sheet as [Worcestershire IV.NE](https://maps.nls.uk/view/101585833),
**surveyed 1881–1882 and published 1887**. Thus the map evidence is later than
our 1865 setting; each major industrial feature still needs a date check. The map
records plan shapes and symbols; it does not establish exact textures, tree
density, pit depths, or building heights.

## Recommended order

1. Trace plot boundaries and minor routes within the existing scene.
2. Add the mapped pit edges and uneven clay ground, keeping depths conservative.
3. Use those land uses to guide scrub and open patches. Retain the requested
   wooded brook; absence of tree symbols is not proof that land was treeless.
4. Establish which railway features predate 1865 before adding that larger system.
5. Return to small pools when water work resumes.

The strongest visual inference is a hamlet among worked industrial ground.
A varied pattern of working yards, old excavations, plots and scrub would make
the setting more specific. This pass records opportunities; it does not silently
remove woodland or introduce undocumented industrial buildings.
