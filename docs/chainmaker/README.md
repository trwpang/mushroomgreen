# The chainmaker study

A separate character demo at `/chainmaker`. This does not place a worker in the village yet.

## Reference and interpretation

The user selected an Alamy photograph in Google Images, titled “Chainmakers, Cradley heath, Birmingham, Victorian period”, image ID 2RWSFPH. The older man wears a low cap, pale shirt, open dark waistcoat and a long worn apron. A moustache and work boots give further character cues.

The figure is an original interpreted worker, not a named resident or an exact portrait. The photograph does not prove the clothing's exact date. No photograph pixels appear in the asset. All mesh geometry and texture images are generated by local Python in Blender.

## Build and runtime

- `npm run chainmaker:model` rebuilds the editable Blender source, staged GLB and validated compressed runtime asset.
- `npm run chainmaker:check` checks TypeScript and samples 560 animation intervals for reach, limb lengths, contact and repeatability.
- `npm run build` verifies the compressed asset hash and byte budget before building the site.
- Authoring source: `scripts/chainmaker/build_chainmaker.py` and `assets/chainmaker/chainmaker.blend`.
- Runtime model: `public/chainmaker/chainmaker.glb`; its manifest records provenance, triangle count, byte count and validation.
- Runtime rig: `src/scripts/chainmaker/rig.ts`. Independent named limb groups use analytic arm poses; continuous fabric bridges cover shoulder articulation. Motion is authored in Three.js, not embedded in the GLB download.
- The torso, neck and face use shaped mesh surfaces. Cloth, leather and skin have locally generated colour and normal images. The apron has thickness and a stitched repair. Boots have heel, sole, laces and toe seams.

The study reuses the central anvil and hearth from the existing forge, with the hearth moved to the side for inspection. It omits the existing loose hammer and hood. New small dark coke lumps replace large bright embers in this close study.

## Motion and controls

One repeating 2.8-second stroke has a slow lift, held preparation, quick strike and small rebound. Both feet stay fixed. Tongs keep one hot link on the anvil. The hammer face meets the link's top surface. The head looks down at the work.

The demo offers work, face and side views, pause/play, strike/raised pose inspection, orbit and zoom. Space toggles motion when the canvas has focus. Reduced-motion preference starts paused. Notes close with Escape and return focus to their control.

Deterministic review links:

- `/chainmaker?still=1` — work view.
- `/chainmaker?still=1&view=portrait` — face view.
- `/chainmaker?still=1&view=side` — side view.
- `/chainmaker?still=1&t=1.904` — exact strike.
- `/chainmaker?still=1&t=1.26` — raised hammer.

## Review

See `review.md` for independent adversarial rounds. Saved screenshots are local evidence in `artifacts/chainmaker/`. The first versions failed and are retained for comparison.

This is a character and stroke demo. It does not simulate heating, turning and welding a full succession of chain links. It has no sound or walking behaviour.
